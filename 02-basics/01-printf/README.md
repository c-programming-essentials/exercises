## Printing to the Console

Write a C program displaying a large 11x9 C using `@` characters.
The expected output is:

```console
   @@@@@@
 @@      @@
@
@
@
@
@
 @@      @@
   @@@@@@
```

To check the correctness of your program, use a [suitable environment](https://github.com/c-programming-essentials/devcontainer) and write your solution in a file named **`printf.c`**. In a terminal, with that file in the local directory, check with this command:

```console
$ check50 02-basics/01-printf
```
