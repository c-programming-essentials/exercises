## Printing a Right-Angled Triangle

Write a C program taking an integer as parameter and printing a right-angled triangle on the command line which legs size is defined by the integer parameter.
Here are some examples of execution:

```console
$ ./triangle 2
*
**

$ ./triangle 5
*
**
***
****
*****

$ ./triangle 15
*
**
***
****
*****
******
*******
********
*********
**********
***********
************
*************
**************
***************
```

To check the correctness of your program, use a [suitable environment](https://github.com/c-programming-essentials/devcontainer) and write your solution in a file named **`triangle.c`**. In a terminal, with that file in the local directory, check with this command:

```console
$ check50 02-basics/12-triangle
```
